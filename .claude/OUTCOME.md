# OUTCOME

## Outcome state

### Behavior

- 利用者が moNa2 を BLE で使っている間、左右間の接続とホストとの接続が切れず、キー入力とトラックボール操作が途切れない。
- 利用者は、画面を見ずに本体の RGB LED の色でバッテリー残量、接続状態、アクティブなレイヤーを判別できる。
- main に push されたコミットごとに、左、右、settings_reset の 3 つのファームウェア（.uf2）がビルドに成功し、利用者がダウンロードして書き込める。
- 利用者は、ファームウェアを再ビルドせずに DYA Studio からトラックボール感度、スクロールの対象レイヤーと速度、エンコーダの回転動作、BLE 接続先、アイドルとスリープの設定を変更できる。
- 利用者は、DYA Studio の診断タブで、フリーズ、クラッシュ、予期しないリセットの記録と、スレッドごとのスタック使用量を確認できる。

## Non-goals

- moNa2 以外のシールド、および Seeeduino XIAO BLE 以外のボードへの対応。
- DYA Studio からのコンボとマクロの編集、OS ごとのデフォルトレイヤー、マウスジェスチャー、キースイッチ診断。

## Constraints

- ZMK は cormoran フォークの `main+dya`（ZMK v0.4 系、Zephyr 4.1）を使う。DYA Studio の診断タブと、スクロールおよびエンコーダの実行時変更がこのフォークの RPC サブシステムを必要とする。
- `config/west.yml` の全 project をコミット SHA またはタグで固定する。ブランチに追従すると、上流の変更でビルドが失敗し続けることがある。
- 右半分を Central にする。トラックボールと USB 接続が右側にある。
- ビルドの確認は GitHub Actions の結果で行う。ローカルに west 環境を持たない。
- ハードウェアは Seeeduino XIAO BLE 2 台、PMW3610、EC11 の現行の配線とピン割り当てのまま変えない。
